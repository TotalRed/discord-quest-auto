Discord Quest Auto

Подключение…

Обычный Discord. Для PTB / Canary укажи полный путь. Перед первым запуском полностью выйди из Discord через Quit.

Токен аккаунта не нужен. Поддерживаются задания на запуск игры, включая выбор любой игры из списка. Награды забираются вручную. Зачёт времени определяет Discord; на Linux он официально не поддерживается. Локальный отладочный порт даёт приложениям на этом компьютере доступ к клиенту — не открывай его в сеть.
